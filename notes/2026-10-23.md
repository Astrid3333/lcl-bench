### Bugs found and fixed this cycle
1. Tinkerbell registry had wrong equations (missing −y², wrong c·x term) and wrong params/x0. Corrected to canonical Wikipedia form: x²−y²+ax+by / 2xy+cx+dy, a=0.9 b=−0.6013 c=2.0 d=0.5, x0=(−0.72,−0.64). Bounded after 5000 iters; lyap1 observed ≈0.1995.
2. Sierpinski chaos game bug: `x = V(k,:)'/2` ignored the previous point. Fixed to `x = (x + V(k,:)')/2`. dim now 1.574 vs 1.585 (rel 0.006–0.007).
3. Hydrogen: full-line FD with cusp `V=−1/|x|` produced spurious interleaved states that `<r>`-filtering could not separate. Replaced with half-line grid for u(r)=r·R(r): h=rmax/(n+1), g=h*(1:n)', Dirichlet both ends, no cusp on grid. Per-potential `sigma` shift (harmonic σ=0, hydrogen σ=−1). E1 rel 6.25e-6, E2 rel 1.56e-6.
4. Barnsley fern box-counting collapsed (slope ~0.61) because box sizes too fine → saturation (N_boxes ≈ n_points). Calibrated: n_points=200000, box_sizes=[0.4,0.2,0.1,0.05], rel_tol=0.05. Slope ≈1.82 vs ref 1.85. Finer eps saturates; document this in entry notes.
5. Runner/evaluator hygiene: `emptychecks()` helper (not `checks=[]` which zeros); `spdiags` off-diagonal length n; `fminbnd` TolX 1e-12 for abs_tol 1e-6; `registry_load` needs the full file path argument.

### Lessons (candidates for AGENTS.md promotion)
- Box-counting on IFS point clouds needs the scaling range sized to the point count: too-fine eps saturates and collapses the slope. Calibrate sizes against n_points and widen rel_tol to the honest run-to-run spread.
- For quantum wells with a cusp potential, put the cusp outside the grid (half-line / domain transform) instead of trying to filter spurious states post-hoc.
- Always verify published chaotic-map equations against a canonical source before tuning the integrator; a wrong equation wastes debugging time on the numerical side.
- octave-mcp `octave_run` hard-caps ~30 s; for long runs (ODE Lyapunov, 200k-point IFS) call `octave-cli --no-gui --eval` via Bash with an explicit generous timeout.
- jsondecode: homogeneous object arrays → struct arrays; heterogeneous → cell arrays; `null` → existing field with `[]`. Normalize in the loader.
