### Bugs found and fixed

**Bug A — `run_one` wrong dispatch argument (`frunner.f90`)**
- 5 families passed `runs(nrun)` (previous/empty slot) instead of local `r`:
  `eval_prng_legacy`, `eval_dsp_bin`, `eval_archimedes_pi`, `eval_prng_bin`, `eval_hybrid_prng`.
- Effect: checks appended into the *previous* entry's stored run; local `r` stayed empty;
  `finish()`/`printrun()` ran on the empty run → entry `pass=true` with no check lines in console,
  JSON slots shifted/mixed (ancestral+vn, vn+wichmann, …, slot 34 empty hybrid).
- git HEAD had correct `r` dispatch for the then-existing families; bug introduced in uncommitted
  changes that also added the new families.
- Fix: all five now pass local `r`.

**Bug B — dotted JSON paths unsupported (`fjson.f90`)**
- `jfind`/`jget` did exact top-level key match only; ~31 dotted reads
  (`"ref.middle_square_cycles.value"`, `"params.digits"`, …) silently returned defaults.
- Visible damage: weyl/hybrid `cycles` ref=0 (real 8), `zero_sink` ref=0 (real 0.1818);
  null-guards "worked" only because missing key → default nanv().
- Fix: `jget` and `jhas` walk dotted paths level-by-level (split on `.`).
  - No registry JSON key contains a literal `.` (verified) → safe.
  - `jhas` uses `jfind` walk (key-exists semantics, including JSON null values);
    `jget` returns JV_NULL for miss *and* null (same as before for single-segment).
  - `jnum`/`jint`/`jstr`/`jnum_req` go through `jget` → free fix.

### Gotcha hit during Bug B implementation
- First `jhas` draft used `jget` + `v%t /= JV_NULL` → would return false for existing-but-null keys
  (old `jfind` returned true). Restored find-walk semantics in `jhas`.
- First `jget` walk used `call jcopy(cur, cur%kids(k))` → **aliasing**: `jcopy` has
  `intent(out)` on `d`, which deallocates `cur%kids` on entry while `s` still points into it
  → SIGSEGV/`Allocatable argument 's' is not allocated` on goertzel (first dotted read).
  Fix: copy through a temporary `nxt` first.

### Lessons
1. **Pass the local accumulator into evaluators, never a pre-indexed array slot** —
   `runs(nrun)` before `nrun=nrun+1` is the *previous* entry; empty local `r` makes
   `finish()` vacuously true while checks land elsewhere.
2. **`jcopy(d,s)` with `intent(out)` on `d` cannot alias `s`** — copying a child into its
   own parent (`jcopy(cur, cur%kids(k))`) deallocates the child array on entry.
   Always stage through a temporary when destination and source share storage.
3. **`jhas` must mean "key exists", not "value non-null"** — JSON null is stored as
   `JV_NULL`, same type as "not found"; existence checks need `jfind`, not type checks.
4. **Dotted-path defaults can mask real refs** — a silent default equal to a plausible
   value (0) looks like a real comparison; always verify `reference` fields in the JSON
   against the registry, not just `pass=true`.
