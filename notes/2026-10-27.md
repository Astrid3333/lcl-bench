# 2026-10-27

## Layer 12: series λ1 estimator (`rosenstein_series`)

Goal: fill `lambda1: None` in `--series` mode with a solo-series estimator,
cableado en `series_fingerprint`, calibrado contra los λ1 oracle, sin romper
la tabla preregistrada (25/25).

### Calibration journey (why not Wolf)
1. **Wolf offset-renorm**: `c = x + (d0/d)(f-x) - pts[j]` is structurally
   broken — the follower displacement comes from the base point (d_max away),
   injecting O(J·d_max) error per renorm → 8–30× overestimate (henon 3.43 vs
   0.419). REJECTED.
2. **Wolf nearest-neighbor repick**: works for maps (henon −5%, logistic
   <1%) but ODEs biased +50–60% (lorenz, persistent across window sizes —
   systematic, not noise), aizawa −25%. REJECTED.
3. **Rosenstein per-pair OLS** (theil=20): identified the real culprits —
   (a) sampling density: nn_med/D 0.0036 (4000 rows) biases selection,
   0.0008 (200k) does not; lorenz bias was density, not method;
   (b) duffing is a 3-D phase-augmented system — its φ ramp column
   (std(diff)/|mean(diff)| < 1e-6) dominates euclidean nn → λ̂≈0; fixing
   with z-score (huge ramp σ → weight only breaks ties) instead of
   dropping columns; (c) mean-of-ln-d curves suffer attrition bias (fast
   pairs saturate first → flatten → factor-0.5 low). Mean of per-pair
   slopes ~9% high on lorenz; MEDIAN of per-pair slopes: worst
   gate-passing error 3.3%.

### Frozen design
- `kernels.lyap1_series`: z-scored metric, anchors (≤2000), Theiler
  window 20, T≤5000, sat 0.2·D, t_min 0, per-pair OLS with min_points 6 /
  min_span 8 / min_pairs 100, **median** of slopes / h.
- Density gate `nn_med/D ≤ 5e-3`: separates accepted (lorenz 0.0036,
  henon 0.0008, logistic 0.0001) from rejected (rossler 0.0169 → 543%,
  aizawa 0.0135 → 74%, duffing 0.0255 → 22%).
- `LAM_REL_SERIES = 0.10` (3× measured worst 3.3%), equivalente conf
  capped at 0.85 (series base 0.75 + 0.10·m).
- 1-column series: delay-embed m=3, τ=first ACF lag < 1/e **for λ1 only**
  — D2/unique_frac stay on raw rows (embedding shifted logistic D2
  0.814→1.004, 23% > 15% tol; raw matches oracle to 1e-11).
- `--series-dt` override; default h = 1.0 (map) / `dt_lyap` (ODE).
- Honest None + `lambda1_reason`: finite box, constant, too short,
  too few pairs, density gate, too few usable fits, bad spacing,
  non-finite slope.

### Lessons
- Calibrate a series estimator at **realistic series sizes**, not just
  dense ones: density (nn_med/D), not the method, was the error driver,
  and it separates cleanly into a gate.
- For per-pair slope aggregates, prefer the median: it cut lorenz error
  9.3%→3.3% and scalar-embedding 16.6%→3.0% at no cost elsewhere.
- Delay embedding must stay scoped to the quantity that needs it (λ1
  geometry); changing the D2 input coordinates breaks oracle comparison.
- `.gitignore` += `tmp_*` for calibration scaffolding (`tmp_calib_ros.py`).
